# VivHelper

适用于 Shared 运行时的 VivHelper 移植。工作区位置：`Mods/VivHelper/`。

项目：

- `Celeste.Mods.VivHelper.csproj`

依赖仓库：**Shared**。先按 [Tools README][tools-readme-zh-cn] 准备 Shared 资源，再构建主项目：

```powershell
dotnet build ./Mods/VivHelper/Celeste.Mods.VivHelper.csproj -c Release
```
