# VivHelper

VivHelper port for the Shared runtime. Workspace location: `Mods/VivHelper/`.

Projects:

- `Celeste.Mods.VivHelper.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/VivHelper/Celeste.Mods.VivHelper.csproj -c Release
```
